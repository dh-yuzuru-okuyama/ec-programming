基礎 01

標準入力・標準出力

競技プログラミングでは、キーボードからデータを受け取り（標準入力）、画面に結果を出力（標準出力）します。Pythonでは input() と print() を使います。

input() は1行分の文字列を読み込みます。数値として使うには int() で整数に変換する必要があります。
Python
# 1行読み込んで表示 s = input() print(s) # 整数として読み込む n = int(input()) print(n + 1) # EC例: 商品名を読み込んで出力 name = input() print("商品名:", name)

基礎 03

if文

条件によって処理を分岐させるには if 文を使います。ECでは「在庫あり/なし」「送料無料/あり」など、条件判定が多く登場します。

インデント（スペース4つ）が重要です。Pythonではブロックをインデントで表現します。
Python
# EC例: 在庫数を読み込んでステータスを表示 stock = int(input()) if stock >= 10: print("在庫十分") elif stock > 0: print("残りわずか") else: print("在庫なし") # 送料無料判定 total = int(input()) if total >= 5000: print("送料無料") else: print("送料あり")
🚀 上のコードをエディタにコピーして、例を実行してみよう！
入力例
3 6800
期待される出力
残りわずか 送料無料
💡 在庫を 0、3、15 に変えたり、金額を 3000 にしたら結果はどう変わる？

基礎 04

for文

繰り返し処理には for 文を使います。複数商品の合計計算や、リスト全体への処理に欠かせません。

range(n) は 0, 1, 2, … n-1 の数列を生成します。入力をN行読み込む場合によく使います。
Python
# EC例: N個の商品価格を読み込んで合計を出力 n = int(input()) total = 0 for i in range(n): price = int(input()) total += price print("合計:", total)
🚀 上のコードをエディタにコピーして、例を実行してみよう！
入力例
5 1200 3500 800 2100 500
期待される出力
合計: 8100
